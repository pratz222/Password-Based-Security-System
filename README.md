# Password Based Security System using Arduino, Keypad, LCD Display

## Project Overview:
This project implements a password-based door lock system using an Arduino, a keypad, and an LCD display. The user can enter a password to unlock the door, and the system provides feedback on the LCD.

## Hardware Components:
- **Arduino Board** (e.g., Arduino Uno)
- **4x3 Keypad**
- **16x2 LCD Display**
- **Breadboard and Jumper Wires**

## Pin Configuration:
- **Keypad Pins:**
  - Row Pins: D1, D2, D3, D4
  - Column Pins: D5, D6, D7
- **LCD Pins:**
  - RS: A0
  - E: A1
  - D4: A2
  - D5: A3
  - D6: A4
  - D7: A5

## Additional Configuration Details:
- **Password:** The default password is set to `"123456"`.
- **Keypad Usage:** Users input their password via the keypad, with `#` used to submit the password.
- **LCD Display Feedback:** The LCD displays messages for access granted or denied, along with prompts for user input.
